# Contractor phone book

Open the contractor menu's **Contractor phone book** link or `/command-center#contractor-phonebook`. The compact directory supports jurisdiction filtering, text/phone search, tap-to-call, email where available, and official source links. It does not send messages or modify customer records.

Contact records live in `platform/client/src/data/contractorContacts.json`. The legacy `platform.html` phone book preserves the same records inline for file-based use. `tests/platform-phonebook.test.js` checks both copies remain aligned. Keep both copies current when updating contacts.
